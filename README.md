# 🏥 Clinic Management System

## 📖 Description
This is a simple Java-based Clinic Management System. It is designed to help clinic staff efficiently manage patient records and organize doctor schedules through an interactive console interface.

## ✨ Features
- **Patient Management:** Add new patient records and view existing patient details.
- **Schedule Management:** Manage and update doctor schedules.
- **Appointment Booking:** Check available time slots for appointments.

## 🛠️ Technologies Used
This project is built using core Java concepts without relying on external frameworks or databases:
- **Java** (Core logic and OOP principles)
- **Arrays** (For data storage and management)
- **Loops & Conditional Statements** (For menu navigation and logic flow)
- **Methods** (For modular and clean code structure)
- **Scanner** (For capturing user input via the console)
